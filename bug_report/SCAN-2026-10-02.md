## Checked and fine

- **Single-store cart**: the server rule holds. `addItem` locks the cart row before reading the
  cart's store. `replaceCart` empties the cart in the same transaction. Checkout rejects mixed stores
  before reserving stock. The migration only trims mixed carts.
- **`scope` paging**: `@IsIn` rejects other values, the `id DESC` tie-break keeps pages stable, and
  the frontend de-duplicates history by id.
- **Geo proxy**: the API key stays on the server and isn't logged, there's a 6 s timeout, and only
  `/geo/config` (the tile key) is public.
- **Address snapshot**: the store order view reads `order.deliveryAddress` (the snapshot), not the
  live address.
