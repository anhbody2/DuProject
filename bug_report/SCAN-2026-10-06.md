## Checked and fine

- **Refresh rotation**: a single conditional `UPDATE … WHERE refresh_token_hash = sha256(old)`, so
  concurrent refreshes can't both win. Only the SHA-256 is stored. `refreshTokenHash` is excluded
  from the default scope, and the `withPassword` scope is only used where the user object isn't
  returned. Suspending an account clears the session, and `/auth/refresh` re-checks the status.
- **Refresh vs access separation** works with the default config: the derived secret
  (`JWT_SECRET + ':refresh'`) differs from `JWT_SECRET`. B44 is about the misconfigured case.
- **Order note**: `@Transform(trim)` → `@IsString` → `@MaxLength(500)`, and blank is stored as
  `null`. React escapes it everywhere it's shown (`pre-wrap`, no `dangerouslySetInnerHTML`).
  `VARCHAR(500)` matches the DTO.
- **Dish flow change**: `/menu?store=` and `/store/:id?dish=` redirects are in place, and
  `CLAUDE.md` describes the new flow (only `docs/SINGLE_STORE_CART.md` is stale, see B45).
